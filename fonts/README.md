# ANSI Regular FIGlet font

`ansi-regular.flf` is from https://github.com/miguelmota/figlet-ansi-regular-font (`ANSI Regular.flf`). Its upstream README identifies the license as MIT. The font is bundled here so the plugin does not depend on a globally installed copy.

Upstream describes it as ANSI Shadow without the shadow; see https://github.com/xero/figlet-fonts/blob/master/ANSI%20Shadow.flf for that font's provenance.
